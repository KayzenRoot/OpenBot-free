# Segurança

Se encontrar uma vulnerabilidade, abra um [relato privado no GitHub](https://github.com/KayzenRoot/OpenBot-free/security/advisories/new) quando essa opção estiver disponível. Caso ela esteja indisponível, use um canal privado com o mantenedor.

Inclua a versão afetada, o impacto observado e os passos mínimos para reproduzir o problema com dados de teste. Compartilhe exemplos com credenciais e dados pessoais removidos.
